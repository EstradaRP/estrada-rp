# Estrada RP

Gestor de campanha do modo Carreira/Realista para Euro Truck Simulator 2.

Organize viagens, receitas, despesas, dias trabalhados, descansos e progressão da campanha. Registros manuais e integração local com o ETS2 para preencher parte dos dados das entregas.

## Downloads

Este repositório reúne a distribuição pública e a documentação. O código-fonte próprio do aplicativo não é disponibilizado aqui.

A primeira versão pública está em preparação. Quando liberada, o pacote Windows estará na seção **Releases**, acompanhado das notas e do arquivo SHA-256.

Escolha **Estrada_RP_1.2.0_Beta_Publico_2026-10-14.zip** quando disponível. Os arquivos automáticos “Source code” do GitHub correspondem a este repositório de distribuição e não contêm o aplicativo Windows.

## Primeiros passos

1. Extraia o pacote completo e leia COMECE-AQUI.md.
2. Se estiver atualizando, exporte antes um backup da campanha.
3. Siga GUIA_DO_JOGADOR.md para configurar o conector com o ETS2 fechado, abrir o jogo e revisar a entrega antes de salvar.

Importar backup substitui a campanha presente; não combina campanhas. O JSON do Estrada RP não é o save do ETS2. Consulte a cobertura de testes nas notas de cada publicação.
