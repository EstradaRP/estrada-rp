# Estrada RP

Gestor de campanha do modo Carreira/Realista para Euro Truck Simulator 2. Organize viagens, receitas, despesas, dias trabalhados, descansos e progressão da campanha, com registros manuais e captura local de dados do ETS2.

## Novidades desta edição

- Temas Claro/Escuro, com preferência preservada.
- Múltiplas carreiras locais, com viagens, regras e finanças separadas.
- BRL ou EUR por campanha, sem conversão cambial.
- Km/mi e litros/galões americanos ou imperiais.
- Backups por carreira e pontos locais de recuperação.
- Atividade opcional no Discord, com correção da ativação após conectar ao ETS2.

## Primeiros passos e atualização

1. Antes de atualizar, exporte um backup JSON de **cada carreira** e preserve o executável anterior. Feche todas as versões do aplicativo.
2. Extraia o novo ZIP para uma pasta nova e abra o executável incluído. Confira carreiras, histórico e livro-caixa antes de continuar.
3. Siga GUIA_DO_JOGADOR.md para instalar/atualizar o conector com o ETS2 fechado. Abra o jogo, selecione a carreira e conecte manualmente.
4. Revise os dados, dias, descansos e despesas antes de salvar a entrega.

Importar permite criar uma nova carreira ou substituir explicitamente uma escolhida; não combina registros. O JSON do Estrada RP não é o save do ETS2. Trocar carreira ou unidades exige reconexão manual. Voltar ao executável antigo não desfaz a migração do perfil; backups novos não têm compatibilidade reversa garantida.
